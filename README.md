# Анализ монетизации онлайн-игры «Секреты Темнолесья»

SQL-проект по исследованию поведения игроков и внутриигровых покупок в онлайн-игре «Секреты Темнолесья».

Основная цель анализа — оценить долю платящих игроков, проверить связь монетизации с расой персонажа и изучить активность пользователей при покупке эпических предметов за внутриигровую валюту «райские лепестки».

## Стек

- PostgreSQL
- SQL
- DBeaver
- CTE
- агрегатные функции
- `FILTER`
- `PERCENTILE_CONT`
- `JOIN`
- сегментация пользователей

## Задачи проекта

1. Рассчитать общую долю платящих игроков.
2. Проверить, зависит ли доля платящих игроков от расы персонажа.
3. Исследовать распределение стоимости внутриигровых покупок.
4. Найти покупки с нулевой стоимостью.
5. Определить наиболее популярные эпические предметы.
6. Сравнить покупательскую активность игроков разных рас.
7. Сформулировать рекомендации для маркетинговой команды.

## Данные

## Ход анализа

### 1. Доля платящих игроков

Рассчитаны:

- общее количество зарегистрированных игроков;
- количество пользователей, покупавших «райские лепестки» за реальные деньги;
- доля платящих пользователей среди всех игроков;
- доля платящих пользователей отдельно для каждой расы.

### 2. Внутриигровые покупки

Для стоимости покупок рассчитаны:

- количество транзакций;
- суммарная стоимость;
- минимум и максимум;
- среднее значение;
- медиана;
- стандартное отклонение.

Отдельно исследованы покупки с нулевой стоимостью. В дальнейших расчётах такие транзакции исключены.

### 3. Популярность эпических предметов

Для каждого предмета рассчитаны:

- количество продаж;
- доля продаж от общего количества транзакций;
- количество уникальных покупателей;
- доля покупателей предмета среди всех внутриигровых покупателей.

### 4. Активность игроков разных рас

Для каждой расы рассчитаны:

- количество зарегистрированных игроков;
- количество и доля покупателей;
- доля платящих игроков среди покупателей;
- среднее количество покупок на одного покупателя;
- средняя стоимость одной покупки;
- средняя суммарная стоимость покупок на одного покупателя.

## Ключевые результаты

- В игре зарегистрировано **22 214 игроков**, из них **3 929** являются платящими. Общая доля платящих пользователей составляет **17,69%**.
- В зависимости от расы доля платящих игроков изменяется от **17,07% у эльфов** до **19,37% у демонов**. Разница между крайними группами составляет около **2,3 п.п.**, поэтому влияние расы на сам факт покупки валюты невелико.
- Всего зафиксировано **1 307 678 внутриигровых покупок**.
- Средняя стоимость покупки составляет **525,69**, медиана — **74,86**, стандартное отклонение — **2 517,35**. Среднее значительно выше медианы, что указывает на выраженную правостороннюю асимметрию и наличие дорогих транзакций.
- Найдено **907 покупок с нулевой стоимостью**, или около **0,07%** всех транзакций. Они исключены из дальнейшего анализа покупательской активности.
- Спрос на эпические предметы сильно сконцентрирован: на **Book of Legends** и **Bag of Holding** приходится более **97% всех покупок**.
- Доля игроков, совершивших хотя бы одну внутриигровую покупку, в зависимости от расы находится примерно в диапазоне **59,97%–62,89%**.
- При этом интенсивность покупок различается заметнее: среднее количество покупок на одного покупателя варьируется от **77,87 у демонов** до **121,40 у людей**.

## Вывод

Раса персонажа слабо связана с вероятностью того, что игрок станет платящим или совершит внутриигровую покупку. Различия между расами заметнее проявляются уже среди вовлечённых покупателей — в частоте и интенсивности покупок.

Для маркетинговой сегментации целесообразнее использовать поведенческие признаки: частоту покупок, сумму трат и предпочтения по предметам. Также стоит отдельно анализировать высокоценный сегмент игроков и причины крайне высокой концентрации спроса на нескольких эпических предметах.
